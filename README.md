
# MAILBOT ASSISTANT

## Descripción
MailBot Assistant es un asistente virtual inteligente diseñado para facilitar la gestión de correos electrónicos empresariales.

## Objetivo
Automatizar la lectura, clasificación y organización de correos electrónicos, además de generar eventos y recordatorios.

## Funcionalidades principales
- Lectura automática de correos.
- Clasificación inteligente por palabras clave.
- Identificación de mensajes urgentes.
- Creación automática de recordatorios.
- Organización de información empresarial.

## Herramientas de desarrollo
- Git: control de versiones.
- GitHub: almacenamiento del repositorio.
- Visual Studio Code: edición del código fuente.
- GitHub Desktop: administración de versiones.
